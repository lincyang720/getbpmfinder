About this tool

Why we built BPM Finder

Checking the tempo or key of a song should be a quick step in making a mix, practicing a part, or putting together a playlist. Some online tools ask you to upload the track or create an account before you can see a result. And when a tool reports a tempo that feels wrong, it can take longer to check the number than it took to find it. We built BPM Finder to give you a free way to analyze a track in your browser and judge how much weight to give the result.

Choose an audio file to see its estimated BPM, song key, Camelot number, duration, and confidence. The browser does the analysis locally. The file stays on your device, and you can use the tool without creating an account.

How tempo and key detection work

First, the browser decodes the audio file into a waveform. BPM Finder measures the energy in short slices of that waveform to build an energy envelope. This is a series that shows how the strength of the audio changes over time. Repeating peaks in the envelope can reveal a pulse even when the individual sounds on each beat differ.

The tempo estimate comes from autocorrelation. The analysis compares the envelope with shifted copies of itself to find time intervals where the pattern lines up. A recurring interval gives an estimate of the beat spacing, which the tool converts into beats per minute.

Key detection uses chroma analysis. It groups pitch energy by note regardless of octave and compares the resulting pattern with profiles for musical keys. The estimated key also appears as a Camelot number so you can read it in the notation used for harmonic mixing.

Who can use it

DJs can check the tempo and Camelot number while planning a set. Producers can use the estimates as a starting point when checking how two tracks might fit together. Musicians can check the tempo before practicing along with a recording, and runners can compare tracks when building a playlist around a steady rhythm.

If you can hear the beat and don't need a file analysis, use tap tempo. Tap along to estimate the BPM without selecting a file.

File limits and variable tempos

BPM Finder supports MP3, WAV, OGG, and M4A. A single file can be up to 30 MB and up to 12 minutes long. Tracks with complex tempo changes can produce an inaccurate estimate because different sections may have different beat spacing. If the number seems off, listen to the section you care about and use tap tempo to check its pulse. The confidence value gives you another cue when deciding whether to double-check a result.
