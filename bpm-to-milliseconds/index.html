How this is calculated

msPerBeat = 60000 / BPM

There are 60,000 milliseconds in one minute. BPM tells you how many beats fit into that minute, so dividing 60,000 by the tempo gives the duration of one beat. At 120 BPM, the calculation is 60,000 ÷ 120 = 500 ms. In common 4/4 time, that beat is normally a quarter note. An eighth note takes half as long, a sixteenth takes one quarter as long, and a thirty-second note takes one eighth as long.

A dotted note includes the original note plus half of its value. That makes a dotted quarter 1.5 beats and a dotted eighth 0.75 beats, so the converter multiplies the beat duration by 1.5 or 0.75. Triplets divide a span into three equal parts instead of two. A quarter-note triplet fits three notes into two beats, making each note two-thirds of a beat. An eighth-note triplet is one-third of a beat.

The calculator always starts with the unrounded beat duration, applies the selected multiplier, and rounds only the displayed result to two decimal places. This avoids compounding a rounding difference at tempos that produce repeating decimals.

What producers use this for

Tempo-synced delay times

Delay plug-ins often offer note-sync controls, but hardware units and some detailed plug-in modes expect milliseconds. Converting the project BPM lets you set repeats that land on the rhythmic grid instead of drifting between beats. At 120 BPM, one beat is 500 ms, so a dotted eighth-note delay is 500 × 0.75 = 375 ms. That setting creates the familiar syncopated repeat pattern heard in rhythmic guitar, synth, and vocal effects.

Aligning samples and drums

A one-shot, percussion tail, or chopped loop can feel late when its useful length crosses the next grid line. Note durations give you precise edit targets. At 120 BPM, a sixteenth note is 125 ms, so you can trim a short hi-hat, move a transient, or set a sampler envelope around that interval. The value also helps when checking whether a delay printed into a sample will reinforce the groove or overlap the following drum hit.

Compressor attack and release

Attack and release controls shape how a compressor follows musical movement. A tempo-related release can return the gain reduction toward zero in time for the next beat or subdivision. Start with a quarter, eighth, or sixteenth-note value, then shorten or lengthen it while listening for pumping and lost transients. For attack, smaller subdivisions provide practical reference points, but the best setting still depends on the source envelope, threshold, ratio, and the compressor's response curve.

Frequently asked questions

Is a 1/4 note the same as one beat?
In 4/4 time, the quarter note normally receives one beat, so a quarter note and one beat have the same duration. Other time signatures can assign the beat to a different note value, so check the meter and the DAW grid before treating them as identical.
Why does my DAW show a different time from this calculation?
A DAW or plug-in may display a rounded value, samples instead of milliseconds, or the final timing after latency compensation. Sample-rate conversion and plug-in delay compensation can change how a time is represented or when audio is heard, even though the BPM-to-millisecond value itself follows the same formula.
How are triplet note times calculated?
A quarter-note triplet fits three equal notes into the time normally occupied by two quarter notes, so multiply the beat duration by 2/3. An eighth-note triplet is half that duration, which is the beat duration multiplied by 1/3.
Does changing the sample rate affect BPM-to-millisecond conversion?
No. The conversion depends only on BPM and note value. Changing the sample rate changes how many digital samples occur during that millisecond duration, but it does not change the duration in milliseconds.
How is a dotted note calculated?
A dot adds half of the original note value. A dotted quarter note is one quarter note plus one eighth note, so it lasts 1.5 beats. A dotted eighth note lasts 0.75 of a beat.
Can I use these values for compressor attack and release?
Yes, these values provide tempo-related starting points for attack and release controls measured in milliseconds. The musical result still depends on the source, compressor design, threshold, and ratio, so adjust by ear after entering a calculated value.
What if the song changes tempo?
Use the BPM of the section where the effect or edit occurs. A single conversion cannot represent multiple tempos at once. For tempo maps, automate the plug-in time or use note-synced mode so the DAW follows each tempo change.
